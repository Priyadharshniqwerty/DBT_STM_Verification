Git Workflow Guide

STM-DBT Verifier — Team branching workflow for github.com/miteshgulati27/DBT_STM_Comversion

For New Team Members One-time setup

1. Clone the repository

git clone https://github.com/miteshgulati27/DBT_STM_Comversion.git
cd DBT_STM_Comversion

2. Set up Python environment

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

Daily Workflow Everyone

Step 1 — Start from latest main

git checkout main
git pull origin main

Step 2 — Create your feature branch

git checkout -b feature/your-feature-name

Examples:

feature/add-wc-lob
New functionality
fix/sql-parser-bug
Bug fixes
enhancement/ui-improvements
Improvements to existing features

Step 3 — Do your work, commit often

# Stage specific files
git add server/routes/compare.py services/rule_engine.py

# Or stage all changes
git add -A

# Commit with a clear message
git commit -m "Add WC LOB support with 12 models"

Step 4 — Push your branch to GitHub

git push origin feature/your-feature-name

Step 5 — Create a Pull Request on GitHub

Go to github.com/miteshgulati27/DBT_STM_Comversion

Click the "Compare & pull request" banner that appears

Add title + description, then click Create pull request

Step 6 — Review and merge

Reviewer approves the PR on GitHub, then clicks Merge pull request

Step 7 — Clean up after merge

git checkout main
git pull origin main
git branch -d feature/your-feature-name

Quick Reference

ActionCommand
See all branchesgit branch -a
Switch to a branchgit checkout branch-name
Get latest maingit checkout main && git pull origin main
Update your branch with latest maingit checkout your-branch && git merge main
See what changedgit status
See commit historygit log --oneline
Discard local changes to a filegit restore filename.py
Stash work temporarilygit stash / git stash pop

Branch Naming Convention

feature/
New functionality
fix/
Bug fixes
enhancement/
Improvements to existing features
refactor/
Code restructuring (no behavior change)

Handling Conflicts

If your push is rejected (remote has newer changes)

git pull origin main --rebase
# Fix any conflicts in your editor, then:
git add .
git rebase --continue
git push origin your-branch
Golden rule: Never push directly to main. Always use a branch + Pull Request.
